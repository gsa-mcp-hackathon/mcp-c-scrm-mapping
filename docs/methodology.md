# Methodology (analytical policies preserved — verified across C-CURE v4/v5, ACL v1/v2)

Full treatment: `C-SCRM_Audit_Methodology_v4.md` (deliverables) §0–§8. Binding rules:

- Live API only; two dollar bases (lifetime vs in-window) never blended; GID primary key, never
  bare PIID; parity-or-rejection per collection phase; FAIL blocks report synthesis.
- Stage 0 triage with orthogonal precision (trigger stripped before scoring; Signal A UEI-graph or
  Signal B taxonomy+sibling noun) and the high-collision ceiling (short/acronym/common/homograph
  stems never standalone); locked manifest governs all downstream stages.
- Strict DEDICATED gate (parent-scope or ≥20% child density, ≤50 children, single awardee);
  BROAD parents contribute only keyword-matched children (retained as evidence, never hydrated
  in bulk); keyword-confirmed broad children are never suppressed (mirage dies by the gate).
- Conglomerate rule: non-pure-play targets need product text or dedicated lineage for Tier-1/2;
  recipient-name-only retention prohibited; sibling lines → TIER_1C; homograph UEIs dropped.
- Ghost rule (termination C1–C4, zero lifetime, ended-zero-window, net-deobligation) with reason
  enums; historical display preserves underlying tier; closed awards with in-window activity keep
  their tier.
- Adjudication bar: regex-only domain nouns are provisional (TIER_2 iff dedicated-parented),
  never Tier-1; boilerplate masked; inflectional derivatives never match brand tokens.
- Cohort-aligned matrix (counts = |G(A,T)|, active/completed split, proof GID per row, phantom
  rows impossible); assisted acquisitions credited to funder with servicing-agency ledger.
- Monetary attribution vocabulary: vendor_associated (identity) vs product_associated (lexical)
  vs product_allocated (explicit allocation evidence only); Tier-1A is never labeled "pure product
  spending" on co-occurrence alone; subaward dollars never added to prime obligations.
- Procurement records establish award associations, not installed products or current dependencies.
